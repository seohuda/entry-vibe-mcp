# EntryVibe 로컬 객체 자산

이 폴더의 `media/*.png`와 `media/beep.mp3`는 이 프로젝트를 위해 새로 만든 원본
기하학 그림과 합성 알림음입니다. 공식 Entry 객체 라이브러리의 사본이 아닙니다.

Copyright (c) 2026 EntryVibe MCP contributors

이 자산과 카탈로그는 저장소 루트의 [MIT 라이선스](../../LICENSE)에 따라 배포합니다.
소리의 재생 시간은 0.444082초입니다. 고양이는 순서가 있는 걷기 모양 두 개를 제공합니다.

재생성은 `python3 scripts/generate-library-assets.py`로 수행합니다. 재생성에만
Python의 CairoSVG와 ffmpeg가 필요하며 MCP 실행, 검색, 컴파일에는 필요하지 않습니다.
